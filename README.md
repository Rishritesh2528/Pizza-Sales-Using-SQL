# 🍕 Pizza Sales Analysis Using SQL

## 📌 Project Overview

Pizza Sales Analysis is a data analytics project that uses **SQL** to explore pizza sales data and uncover meaningful business insights. The project focuses on understanding order trends, customer preferences, pizza category performance, and revenue generation.

Through a series of basic, intermediate, and advanced SQL queries, this project analyzes sales performance and identifies the most popular pizza types, preferred pizza sizes, peak ordering hours, and top revenue-generating products.

## 🎯 Project Objectives

* Calculate the total number of orders and total revenue generated.
* Identify the highest-priced pizza and the most frequently ordered pizza size.
* Find the top 5 most ordered pizza types based on quantity.
* Analyze the total quantity of pizzas ordered by category.
* Determine the distribution of orders by hour of the day.
* Calculate the average number of pizzas ordered per day.
* Identify the top 3 pizza types based on revenue.
* Analyze the percentage contribution of each pizza type to total revenue.
* Calculate cumulative revenue over time.
* Identify the top 3 revenue-generating pizza types within each category.

## 🛠️ Tools & Technologies

* **SQL** – Data querying, analysis, and business insights
* **MySQL** – Database management and query execution

## 🔍 SQL Concepts Used

* SELECT and WHERE
* Aggregate functions: `SUM()`, `COUNT()`, `AVG()`
* `GROUP BY` and `ORDER BY`
* JOINs
* Subqueries
* Common Table Expressions (CTEs)
* Window functions
* Date and time functions
* Revenue calculations and ranking

## 📊 Key Areas of Analysis

1. **Sales Performance:** Total orders, revenue, and product pricing.
2. **Customer Ordering Patterns:** Popular pizza sizes and order distribution by hour.
3. **Product Analysis:** Top-selling pizza types and category-wise demand.
4. **Revenue Analysis:** Revenue contribution, cumulative revenue, and category-level rankings.
